# Changelog

All notable changes to Emvera are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-07-20

### Added

- Authenticated personal-finance workflows for manual data, validated CSV imports, and Plaid Sandbox synchronization.
- Email activation, password recovery, confirmed TOTP enrollment, and per-session OTP challenges.
- Debt payoff planning, payment reminders, credit-score history, investment analysis, and virtual competitions.
- PostgreSQL/Docker deployment path, health probes, dependency auditing, and a 205-test verification suite.
- Architecture, deployment, integrations, security, contribution, and interview-demo documentation.

### Fixed

- Portfolio headline value now reports the sum of the current user's holdings rather than the newest single holding.
